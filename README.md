
# Wheel of Success

A fun and interactive browser-based word guessing game inspired by “Wheel of Fortune.”  
Users try to guess a hidden phrase by selecting letters, with a limited number of incorrect guesses allowed. It demonstrates DOM manipulation, event handling, and game logic with vanilla JavaScript.

🔗 **Live Demo**: [Wheel of Success](https://epetaway.github.io/WHEEL-OF-SUCCESS/)

## ✨ Features

- Random phrase selection each game
- On-screen keyboard for letter guesses
- Visual feedback for correct/incorrect guesses
- Limited number of lives (represented by hearts)
- End game screen with restart option
- Clean, responsive design using flexbox

---

## 🎮 Game Rules

- Click letters to guess the hidden phrase.
- Correct guesses reveal matching letters in the phrase.
- Incorrect guesses remove a heart (life).
- You win by guessing the whole phrase before running out of lives.

## 🚀 Getting Started

### Prerequisites

No setup required — just a browser!

### Local Installation

1. Clone the repository:

  bash
   git clone https://github.com/Epetaway/WHEEL-OF-SUCCESS.git


2. Open the folder:

   ```bash
   cd WHEEL-OF-SUCCESS
   ```

3. Open `index.html` in your preferred browser:

   * Double-click the file, or
   * Right-click → Open with → Browser
